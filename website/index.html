Buoy

An island for your notifications, promises and background work.

Star on GitHub

Try it

buoy('Link copied', { icon: 'link' });

The island at the top of this page is the real component. Press a button and watch it change.

Live activities

const timer = buoy.live({ label: 'Focus timer', expandable: true, render });
setInterval(() => timer.refresh(), 1000);

Things that keep going stay on the island until you stop them. While a timer, song, call or recording runs, tap the island to open its controls.

One shape, every state

Nothing stacks and nothing jumps. The same element changes its size, icon and label.

Two lines to start

Render the island once. Call it from anywhere, even outside React.

import { Buoy, buoy } from 'buoy-ui';

export default function App() {
  return <Buoy />;
}

buoy('Link copied', { icon: 'link' });

Messages, promises, tasks and every option are covered in the README.
